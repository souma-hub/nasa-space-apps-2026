1. **「友人の農家」から始める。** 数字より先に、誰が困ったかを言う

## 台本の骨子
1. 掴み: 予報が出たら、青い稲でも刈るしかない
2. 損失: 23 回のうち 16 回は被害なし
3. 原因と問い: 判断基準がない。NASA のデータで作れるか
4. 入力: 雨と風と、実り具合
5. 結果: 茨城・千葉 → 全国 → 統一モデル、1 つ抜きの数字、限界を自分から
6. デモ: 予報から「刈る／待ってよい」
7. 展望: 記録から作付けへ。農家の判断は置き換えない

## 想定質問と答え（Q&A 対策）
| 質問 | 答えの方針 |
|---|---|
| 台風 23 個では少なすぎないか | その通り。だから同じ手順を全国（台風 86 個、1,815 行）に広げて確かめ、1 つ抜きで検証した。台風が増えれば係数は更新できる |
| 見逃しは危険ではないか | 1 つ抜きでは 1/7 の見逃し（房総半島台風）がある。小さく強い台風で NASA の風が弱く出たため。ツールは判断材料であって、農家の判断を置き換えない。見逃しゼロを保証しない |
| 正解は倒伏そのものか | 違う。農水省の災害統計は風水害の合計。被害 ha は年・災害単位で、同じ年の台風に同じ値が付いている |
| 早刈りした田は倒れないのでは | その通り。予報で先に刈ると被害が小さく記録され、強い台風ほど過小評価になりうる |
| 判断の時点では雨は予報だが | GEOS-FP の予報で評価し直す必要がある。未検証。学習（MERRA-2 系）と予報（GEOS-FP）は同じ GEOS 系なので癖が揃う、というのが期待 |
| 風は見ないのか | 見る。全国では NASA の風が効き、台風との距離の代わりでもない（距離を入れても風は有意に効く）ので、統一モデルに入れた。関東だけでは、突風を POWER が再現できない（2019 年 15 号で 6.9 vs 45.8 m/s）ことが壁だった |
| 茨城・千葉と全国でモデルが違うのは、一般化と矛盾しないか | 違わない。1 つの式（全国の部分＋地域の追加項）で、茨城・千葉は地元の知見（実り具合）を追加項として足しただけ。手順（被害統計→NASA のデータで検定→台風単位の交差検証）も共通 |
| 早刈りでどれだけ損をするのか | 数字は持っていない。公的資料で確認できるのは、適期（千葉・茨城で出穂後 35〜40 日）より早いと未熟粒が増えて等級が下がること。減収率は確認できていない。だから「損失の大きさ」ではなく「判断基準がない」ことを問題にしている |
| 大雨は増えているのか（気候の変化） | 全国では強い雨が増えている（気象庁）。関東南部の 8〜9 月に有意な長期トレンドは見えない（POWER）。2026 年は記録的だが、1 年では傾向と言えない。だから記録する。線状降水帯の長期統計は確認できていない |
| お題は輪作だが、関係あるのか | 直接は違う。年単位の気候から作付けを決める道は検定で否定した。履歴をためれば、品種と田植え日、さらに輪作の比較に広げられる。展望として語る |
| ENSO で関係がなかったのは失敗では | データが示した結果。否定された結果を出すことが、誠実さの証拠 |
| NASA のデータをどこで使ったか | GPM IMERG、POWER（MERRA-2 元）、GEOS-FP。Sentinel-1 は ESA で NASA ではない（失敗した手法として 1 文） |
| 農家は本当に使うか | まず友人 1 人。「刈る／待ってよい」の 2 択に絞る。GPU 不要で、事務用の PC で動く |
