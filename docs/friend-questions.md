# 友人（米農家）への質問

最終更新: 2026-11-14 午後（方針の組み替えに追随）。答えは `PLAN.md` と開発側のパラメータに反映する。

> **2026-11-14 夕方の更新**: 優先度 1（晴れでも刈るか）は、成果物の価値（しなくてよい早刈りを減らす）に直結する。品種の割合は `phenology.py` の仮置きの確認用。`docs/priorities.md` を参照。

## 前提の変更
友人は若く、**過去の嵐ごとの倒伏は聞けない**（ヒアリング済み）。そのため、正解データは農水省の災害統計で代える方針になった。**嵐の表を送って「倒れたか」を聞く質問は不要になった。**
友人に聞くのは、モデルの入力（品種、生育段階）と、現場の判断のところだけ。

## すでに聞けたこと（PLAN.md のヒアリングより）
- 今の対応: 台風の予報が出たら刈り取る
- 稲が青いうちはあまり倒れない。背が低い品種は倒れにくい
- 主な品種（オーナーの見立て）: コシヒカリ、ふくまる、あきたこまち、にじのきらめき

## まだ聞きたいこと（優先度順）
| 優先 | 聞くこと | 使い道 |
|---|---|---|
| 1 | 台風の予報が出たとき、**晴れでまだ刈りたくない状態でも刈るか**（オーナーが確認中） | 「待つか、刈るか」の現場の実態。発表の掴みにも使える |
| 2 | 品種ごとの作付割合と、倒れやすさの順（背の高さ） | `phenology.py` の「倒れやすい田の割合」が仮置きのため。精度に直結 |
| 3 | 品種ごとの出穂日、田植えの日、刈り取りの日（おおよそ） | 推定出穂日（コシヒカリ平均 7/29）の答え合わせ |
| 4 | 今年倒れた日と範囲（何割くらいか）、田んぼの場所（市町村まで） | 唯一の田んぼ単位の正解。検証に使う |
| 5 | 倒れた稲の写真を発表で使ってよいか（名前・場所は出さない） | スライド 1 枚目 |
| 6（展望用。今回は使わない） | 倒れたときの減収は何割か。早く刈ると収量・品質がどれくらい落ちるか | 刈り時の損得の計算（今後の展望） |

## そのまま送れる文面（LINE 用の例）
> 今、NASA のハッカソンで「大雨や台風の予報から、稲が倒れるかを予測する」モデルを作ってる。君の田んぼの件がきっかけだよ。
> 教えてほしいのは次のこと。分からないところは「分からない」でOK。
> 1. 台風の予報が出たとき、まだ実りきっていない稲でも刈る？ それとも様子を見る？
> 2. 君の周りの主な品種の割合と、どれが倒れやすいか（コシヒカリ、ふくまる、あきたこまち、にじのきらめき以外もあれば）
> 3. 品種ごとの、出穂・田植え・刈り取りのだいたいの時期
> 4. 今年倒れた日と、広さ（何割くらい）、田んぼのある市町村
> 5. 倒れた稲の写真を、名前や場所を出さずに発表で使ってもいい？
> 答えは明日の午前中までにもらえると助かる。
