# 友人（米農家）への質問

最終更新: 2026-11-14。答えは `events.csv` と `PLAN.md` に反映する。

## なぜ聞くのか
公的な資料には「倒れた」記録はあっても、「倒れなかった」記録がない。風雨が強かった嵐のうち、倒れなかったものが分からないと、危険の境目（閾値）が決まらない。**「倒れなかった」も「倒れた」と同じくらい大事。**

## 優先度の順
| 優先 | 聞くこと | 使い道 |
|---|---|---|
| 1 | 下の表の嵐で、自分の田んぼ（や近所）は倒れたか、倒れなかったか、覚えていないか | 「倒伏なし」のラベル。閾値と交互作用の検定に必須 |
| 2 | 田んぼの場所（市町村まで）と、今年倒れた日・範囲（何割くらい） | 正解データ。気象の地点を選ぶ |
| 2 | 普段、何を見て刈り取りの日を決めるか。早く刈ると、収量や品質がどれくらい落ちるか | 「待つか、刈るか」の損得。収量が伸びる速さ |
| 2 | 倒れたとき、減収はどれくらいか（何割）。等級や、刈り取りの手間はどう変わるか | 倒伏の被害額。待つリスクの大きさ |
| 3 | 品種、田植えの日、出穂の日、刈り取りの日（毎年おおよそ） | 生育段階の推定。倒れやすさの説明 |
| 4 | 肥料（窒素を多めに入れるか）、植え方（密か疎か） | 茎の強さの説明 |
| 5 | 倒れた稲の写真を発表で使ってよいか。名前や場所は出さない形で | スライド 1 枚目 |

## そのまま送れる文面（LINE 用の例）
> 今、NASA のハッカソンで「稲の倒伏が、どんな風と雨で起きるか」を調べてる。君の田んぼの件がきっかけだよ。
> 教えてほしいのは、昔の台風や大雨のとき、**倒れた年と、倒れなかった年**のこと。倒れなかったほうが特に大事。
> 覚えてる範囲で、次の年の田んぼはどうだった？（倒れた／倒れなかった／覚えてない）
> 2016年8月（台風9号）、2011年9月（台風15号）、2010年9月下旬、2001年9月（台風15号）、2007年9月（台風9号）、2013年9月（台風18号）、2017年9月（台風18号）、2021年8月
> それと、普段は何を見て刈り取りの日を決めてる？ 早く刈ると収量や品質はどれくらい落ちる？ 倒れたときは、収量が何割くらい減って、刈り取りの手間はどう変わる？
> あと、品種と、田植え・出穂・刈り取りのだいたいの時期、今年倒れた日と広さも分かれば教えてほしい。
> 倒れた稲の写真を、名前や場所を出さずに発表で使ってもいい？
