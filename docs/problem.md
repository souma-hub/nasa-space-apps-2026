# 課題発起と仮説（発表の土台）

最終更新: 2026-11-14。開発の結果が出たら、★の箇所を実測値で更新する。

## 1. 課題発起（なぜこれをやるのか）

### ひとことで
友人の米農家の田んぼが、台風と大雨で倒れた。農家は倒れてから気づく。倒れる前に知る手段がない。

### 課題の構造
| 層 | 内容 |
|---|---|
| 現場の困りごと | 倒伏すると収量と品質（等級）が落ち、刈り取りも遅く、手間がかかる。農家は被害が出てから知る |
| 既存の手段の限界 | 気象予報は「大雨・強風」を出すが、「自分の田んぼが倒れるか」は教えない。公的な被害統計は県・年単位で粗く、事後にしか出ない |
| データの空白 | 「倒れた」記録はあっても「倒れなかった」記録がない。そのため、どこからが危険かの閾値が決められない |
| NASA の出番 | 衛星（SAR・光学）と地球観測の気象・土壌水分データで、田んぼ単位・日単位の情報を事前に出せる可能性がある |

### チャレンジとの対応（Be An Earth System Trend Detective!）
- 複数の地球システムの変数（風・雨・土壌水分・稲の生育）の「関係」を探す課題。倒伏は風と雨と土壌と作物が絡む典型例
- 「相関を見つけて終わり」ではなく、統計で確かめ、農家が使える形にするところまで行う

## 2. 仮説

### 主仮説（H1）: 風は雨の補正係数になっている
倒伏は「稲を倒す力（風）」が「稲の耐える力」を超えたときに起きる。雨は穂を重くし、根元の土を緩めて、耐える力を下げる。したがって雨と風は足し算ではなく **掛け算（交互作用）** で効く。

- 予想される姿: 暴風だけでも、大雨と中程度の風でも倒れる。境界線は右下がりの曲線になる（雨が多いほど、少ない風で倒れる）
- 根拠（現時点）: 関東南部で倒伏が確認できた 3 つの嵐は 2 種類に分かれた
  - 暴風型: 2019-09（最大瞬間風速 45.8 m/s で 117 位中 1 位、雨は 12 位）
  - 大雨＋中程度の風型: 2023-09、2026-08（瞬間 17 m/s 前後で 60 位前後、雨は 5 位・7 位）
- 検定: 倒伏あり 3 vs 報告なし 113。雨 p=0.004、最大瞬間風速 p=0.17（片側 Mann-Whitney）
- 注意: 大雨型 2 つは冠水も同時に起きており、「雨が効く」のか「冠水が効く」のか切り分けきれていない

### 副仮説
| 番号 | 仮説 | 確かめ方 |
|---|---|---|
| H2 | 稲の生育段階（出穂後の日数）が進むほど倒れやすい。穂が重くなるため | POWER の気温から積算温度を出し、出穂日を推定。嵐の日との差を説明変数に入れる |
| H3 | 嵐の前の土壌水分が高いほど、同じ風で倒れやすい | NASA POWER の GWETTOP / GWETROOT |
| H4 | 7 月の日照不足は茎を弱くし、秋の倒伏を増やす | POWER の日射量と気温 |
| H5 | 雨が先、風が後の順番だと倒れやすい（濡れてから揺さぶられる） | 時間値で「X mm の雨の後 Y 時間以内の強風」を特徴にする |

### 「ならない」場合の仮説（誠実さのために先に書いておく）
- H0: 風と雨の交互作用は有意でなく、足し算のモデルで十分。→ その場合の主張は「雨量が最良の単独指標」になる
- 正例が少ない（3〜）ので、「有意でない」は「効かない」ではなく「このデータ量では分からない」と書く

## 3. すでに分かった事実（試して駄目だったものも成果にする）

| 試したこと | 結果 | 発表での位置づけ |
|---|---|---|
| Sentinel-1（C バンド SAR）で画素単位の倒伏検出 | 軌道 141 と 39 の変化の相関 r≈0.05。ノイズと区別できない | 「衛星だけでは見えなかった」 |
| 筆ポリゴンで田 1 枚ごとに平均（16,295 区画） | 相関 r≈0.02〜0.04。水の状態と早生の収穫に埋もれる | 同上。処理のずれではないことも確認済み |
| NASA POWER の風 | 台風の突風を再現できない（2019-09-09: POWER 6.9 m/s、アメダス最大瞬間 45.8 m/s） | 「粗い再解析の限界」。風はアメダスで補う |
| 農水省の年統計 | 嵐の指標と有意な相関なし（ρ≤0.46, p≥0.10） | 「粗すぎて使えない」→ 田んぼ単位の必要性を裏づける |
| 雨量 | 倒伏あり 3 の雨は報告なしと有意に違う（p=0.004） | 使える信号 |

## 4. 欠けているもの（開発待ちの間に詰める項目）

- ★「倒伏なし」のラベル（オーナーが友人の農家に聞く）。これが無いと閾値が決まらない
- ★交互作用の検定結果（案 A: Firth 補正つきロジスティック回帰、案 B: 物理的な倒伏指数）
- ★嵐単位の交差検証の精度（1 つ抜いて当てる）
- 友人の田んぼの場所・品種・出穂日・肥料
- マイコン（ESP32）デモの有無（ロジスティック回帰なら係数を C の配列に書くだけ）

## 5. 想定ユーザーと価値

| ユーザー | 価値 |
|---|---|
| 米農家（まず友人） | 嵐が来る前に「今回は倒れる確率が高い」と分かる。早刈り・排水・見回りの判断に使える |
| JA・自治体 | 被害の見込みを早く出せる。被害報告の聞き取りの優先順位がつく |
| 保険（農業共済） | 事後の被害確認を補う客観データ |

## 6. 発表で使う言い回し（素材）
- 「風速だけを見ても、倒れた田んぼは見つかりません。雨と掛けて初めて見えてきます」
- 「衛星では見えませんでした。見えなかった理由まで確かめたのが、今回の成果の半分です」
- 「公的な統計には『倒れた』はあっても『倒れなかった』がありません。だから閾値が決まらない。ここを埋めるのが次の一歩です」
