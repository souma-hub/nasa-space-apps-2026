## 2. 捨てるもの
| 捨てるもの | 理由 |
|---|---|
| 3 つ目以降の作付戦略（田畑輪換の麦・大豆）、輪作の比較 | 範囲外（開発側の決定） |
| SMAP・ECOSTRESS・GRACE など未使用のデータ、土の健康・水の節約・窒素固定 | 使っていない（開発側の決定） |

| 「風は雨の補正係数」（雨×風の交互作用）を柱にすること | 最終の規則に風を入れていない。発表の主張にしない（`docs/problem.md` の H1 は資料として残す） |
| 年トレンドの警報回数（Trend Detective 用のスライド） | 倒伏の条件に当たった台風の数に年トレンドなし（Kendall τ=−0.07, p=0.51）。成果ではなく否定の結果 |
| 衛星 SAR・筆ポリゴンの詳細 | 失敗した手法。発表では 1 文 |
| 手法の一般化を成果のように語ること、OSS 化、極限環境（ESP32）の展開 | 未検証。展望の脇役（`docs/design-principles.md` に残すが、発表の中心にしない） |

資料の本文は消さず、この表で「発表に使わない」と決める。聞かれたときの根拠が残るため。

## 3. 成果物の事実（`PLAN.md` と `results/` から。数字はこれを正とする）
**規則（NASA のデータだけ）**: IMERG の雨が 30 mm 以上 かつ コシヒカリ出穂後の積算気温（POWER の気温から推定）が 400℃ 以上 → 「刈る」。それ以外 → 「待ってよい」。

| 検証 | 結果 | 注意 |
|---|---|---|
| 対象 | 2004〜2021 年の 8〜9 月に関東南部から 300 km 以内に来た台風 22 個。農水省の統計で茨城＋千葉の水稲被害 100 ha 以上は 6 個、被害なしは 16 個 | 台風が少ない。被害の正解は風水害の合計で、倒伏だけではない。被害 ha は年・災害単位で、同じ年の台風（2016 年の第 7 号と第 9 号）に同じ値が付いている |
| 今のやり方（警報が出たら全部刈る） | 22 回刈り、うち 16 回は被害が出なかった | |
| 規則を過去に当てはめた結果 | 見逃し 0、22 回中 10 回の早刈りを省けた（被害なし 16 個のうち 10 個で「待ってよい」） | **過去に合わせ込んだ値**。未来の性能ではない |
| 1 つ抜きの検証（より正直な数字） | **見逃し 1 / 6**、被害なし 16 個のうち **8 個**で「待ってよい」 | 発表ではこちらを先に言う |
| ヒアリングとの一致 | 「稲が青いうちは倒れない」: 2009 年 9 号・2021 年 10 号は大雨でも出穂後 300℃ 台で被害なし | 物理の裏づけとして使える |
| 予報での評価 | まだ。判断の時点では雨は予報（GEOS-FP）になる | 未検証。限界として言う |

**お題への接続の試み（否定された）**: エルニーニョ・ラニーニャ（ONI）と、台風の数・倒伏の条件に当たった台風の数（1981〜2026 年、52 個）の関係は**なし**（Spearman ρ −0.06〜+0.14、p≥0.35。3 区分の差も Kruskal p≥0.27）。年単位の気候から作付計画を決める道は、データでは無理だった。
- 発表での言い方: 「お題に沿って、年単位の気候から作付けを決められるかを考え、検定した。関係はなかった。代わりに、収穫判断で役に立つものを作った」。否定の結果を隠さないことが、誠実さの根拠になる

## 4. 短期の「完成」の定義
- [x] NASA のデータだけの規則で、22 台風を判定した（`analyze_early_harvest.py`）
- [ ] 予報（GEOS-FP）を入れて「この予報なら刈る／待ってよい」を出すデモ（`fetch_geos_forecast.py`）

## 5. 公式 Objectives との対応（正直な評価）
| Objectives の要素 | 我々の対応 | 強さ |
|---|---|---|
| NASA の地球観測と地域の農業情報の組み合わせ | IMERG（GPM）、POWER、GEOS-FP ＋ 農水省統計・品種・友人のヒアリング | 強い |
| 使ってよい NASA データ（GPM、POWER など） | IMERG は GPM。POWER。一致 | 強い |
| 極端な降水、気象の変化への強さ（resilience） | 大雨の予報で、被害が出るかを判定する | 中 |
| 現在の作物がどの季節に弱いか（vulnerable seasons） | 出穂後 400℃ 以上（倒れうる時期）。青いうちは倒れない | 中 |
| 農家の判断を置き換えない支援 | 「判断するのは農家。刈る／待ってよいの材料を出す」 | 強い |
| 情報の欠けとリスクの明示 | 限界を先に言う（上の表） | 強い |
| 3 つ以上の輪作戦略の比較 | 未実装。展望 | 弱い |

審査の Relevance（課題との関連）では、輪作そのものではない点が弱くなりうる。だから**展望**を作り込んで、結びつきを語る。

### 展望: 履歴から作付計画へ
1. 予測と結果（刈った／待った、被害が出た／出なかった）の履歴をためる。過去 25 年を同じ規則で再計算すれば、履歴は今すぐ作れる
2. 履歴から「この品種・この田植え日は、過去に危険な年が何回あったか」が分かる（出穂後積算気温は品種と田植え日で決まる）
3. 品種と田植え日の組み合わせを、既存のやり方を含む 3 通り以上で比べられる
4. さらに、輪作（稲以外を挟む）まで広げれば Objectives の本題に届く
- 言い方: 「今回は土台になる、収穫判断の支援を作りました。履歴をためれば、作付計画の比較に広げられます」
- 注意: 展望であって、今回は作らない・検証していない。そう言う
